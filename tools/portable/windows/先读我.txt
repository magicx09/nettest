proxy-node-audit 便携版（Windows）
==================================

这是什么
--------
一套「测代理节点质量」的工具，已经把需要的东西全塞进这个文件夹：
自带 bash（MSYS2 环境）、python3、mihomo、nexttrace、jq、curl。
目标机器上**什么都不用装**。

⚠ 先说清楚（重要）
------------------
Windows 版是**搭好了但没在真机上验证过**（作者手上没有 Windows 机器）。
代码路径、打包内容都做过静态检查，但「第一次运行会不会踩到环境坑」不敢保证。
如果你跑出问题，请把 `pnq.cmd --check` 的完整输出留下，那是最有用的信息。

快速开始
--------
1) **整个 .zip 解压成一个文件夹**（用 7-Zip / WinRAR / Bandizip 都行）。
   不要在压缩软件的预览窗口里直接点运行，那样会缺文件。
   也别放在 C:\Program Files 下面（那里没有写权限，报告写不出来）。
2) 双击 `双击运行.cmd`（或 `run.cmd`，两个一样）。
3) 它会先打开一个黑窗口，把订阅链接粘进去，回车。
4) 跑完报告在  out\latest\REPORT.md

命令行用法（在文件夹里按住 Shift 右键 →「在此处打开 PowerShell/终端」）
--------------------------------------------------------------------
   pnq.cmd --check                环境自检，**第一次强烈建议先跑这个**
   pnq.cmd "你的订阅链接"           一键全量评测
   pnq.cmd --help                 全部参数

注意事项
--------
· 首次运行 Windows 防火墙可能弹窗问是否允许 mihomo 联网，选「允许」。
· 杀毒软件可能报 mihomo.exe / nexttrace.exe：它们是开源的网络测速/路由追踪工具，
  会被启发式规则误报。要么加信任，要么选「仍要运行」。
· 中文路径、带空格的路径都支持，不用特意改成英文目录。
  （唯一的要求：别放在 C:\Program Files 这类只读位置——包会把结果写在
  自己目录下的 out\ 里，那里写不进去。）
· 订阅链接必须是 Clash / Mihomo 格式（结尾一般带 &flag=meta）。
  在 cmd 里粘贴链接时注意 `&` 是 cmd 的特殊字符——所以**建议用
  `双击运行.cmd` 或 `pnq.cmd` 不带参数（会提示你粘贴），这样最省事。
· 自检里会看到 mtr / iperf3「未包含」：它们体积大且需要额外权限，本包不含，
  对应的两项会显示为未测，不影响其它维度评分。

报告怎么看
----------
· 表格里的「—」表示**没测到**，不是 0 分；评分会把缺的维度权重去掉再算。
· 重点看：总分、IP质量、速度、稳定性、链路、出口 IP / 国家 / ASN。
· 过程日志在 out\latest\run.log，报错时贴它。

跑多久
------
几十个节点默认流程约 10~20 分钟；节点多或开 --full 可能半小时以上，别关窗口。

卸载
----
删掉整个文件夹即可，不往系统里写任何东西（注册表、服务、环境变量都不动）。
